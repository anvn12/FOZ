# Quickstart: Threads-Style Community Database Schema

1. Open the feature specification at [spec.md](./spec.md) and confirm the scope matches the proposal.
2. Review [plan.md](./plan.md) to verify the technology and constitution checks.
3. Read [data-model.md](./data-model.md) to inspect entities, relationships, and validation rules.
4. Use [research.md](./research.md) to understand the design decisions and rejected alternatives.
5. Review the schema modules under `src/backend/db/schema/` and the shared enums in `src/shared/schema-enums.ts`.
6. If runtime schema work is extended later, keep the implementation in `src/backend/` and shared validation in `src/shared/`.
7. Re-run the checklist in [checklists/requirements.md](./checklists/requirements.md) before moving to task generation.
