- ko phải use case (uc) nào cũng có nhiều test case (tc) để làm thì giờ 1 uc 5 cái tc còn 1 uc 15 cái tc bù qua lẫn nhau đc ko hay là 2 cái đều phải 10 tc

- phần auto-gen tc từ speckit khi mà mình đổi có cần ghi vô changes để biết mình đổi gì ko hay chỉ cần file sau khi sửa là đc. Với cả phải sửa tất cả các tc của các feature hay là tc của các feature mà có uc được chọn, hay là chỉ cần các uc mình chọn thôi.

- test case document gồm những gì (các file test case từ speckit đã chỉnh sửa hay sao)

- cái bug report, test report, test summary với test case document kia là viết theo format như nào (kiểu là 1 file riêng r link vô hay gộp chung vô phần A luôn).

- documented result cần những thứ gì

- mấy cái bug status với severity là gồm những giá trị gì (open/fixed, major/minor, ...)
