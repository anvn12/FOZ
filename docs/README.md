# Documentation Directory (`docs/`)

This directory contains all the project documentation, design assets, and administrative records for the FOZ project.

## Directory Structure

- **`00 - Old-PA-docs/`**
  - Contains older or previous PA related documentation.

- **`01 - PA/`**
  - For PA submissions.

- **`02 - Meeting-minutes/`**
  - Notes and records from team meetings.

- **`03 - UI-designs/`**
  - Contains UI mockups, design assets, and prototypes for various features.

- **`QA report/`**
  - Reports and documentation related to Quality Assurance and testing.

- **`Techstack/`**
  - **CRITICAL**: This is the binding baseline and source of truth for the project's technology stack (`be.md` and `fe.md`). According to the project constitution, any changes to the tech stack must be reflected here. Do not delete or move this folder without amending the constitution.

- **`ideas/`**
  - Contains design docs, draft concepts, and scratchpad files (e.g., `ai-usage-log.md` which documents the AI logging skill).

## Root Files

The root of this directory contains:
- `AI-Log-Setup.md` (Setup guide for the AI logging framework)
- `README.md` (This file, describing the structure of the `docs` directory)
